# Clasificación de Spalling en Concreto mediante Aprendizaje Automático

## Experimentos

Este proyecto es una aplicación interactiva desarrollada con **Streamlit** para la clasificación de *spalling* en concreto. Incluye notebooks para replicar los experimentos, así como los modelos entrenados en formato `.pkl`.

El propósito de este proyecto es clasificar la presencia o ausencia de *spalling* en concreto utilizando modelos de aprendizaje automático. El flujo experimental incluye el preprocesamiento de datos, entrenamiento de modelos y comparación de clasificadores.

Para ejecutar los notebooks y entrenar los modelos, se requieren las siguientes librerías:

```text
streamlit
pandas
numpy
joblib
matplotlib
scikit-learn
```
## Aplicación

La aplicación requiere las librerías listadas en el archivo requirements.txt. Fue desarrollada utilizando el framework Streamlit y 
desplegada en Streamlit Cloud en el siguiente enlace:

[Aplicación de Clasificación de Spalling](https://concrete-spalling-using-classification-models.streamlit.app/)
